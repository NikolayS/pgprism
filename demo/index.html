pgscope

Zero-dependency PostgreSQL EXPLAIN visualizer and JSON-to-text translator for PG 15–19. Accepts JSON or text plans, converts buffers in 8 KiB blocks to IEC binary units, and links diagnostics straight to plan nodes.

Paste your own EXPLAIN (JSON or text)

Tip: switch between Table, Tree, Flame, Text (translated via jsonToText when given JSON), and JSON. Click any row, tree node, flame bar, or diagnostic link to inspect exclusive vs inclusive timing, buffers, and PG 15–19 telemetry.
